# Shared frame renderer

`selectSpecies(collection, settings, now)` is the Worker-facing pure selection function. Invoke after confirmed collection/settings changes and from an hourly hosted schedule. Device manifest polling must only read the persisted revision. Week membership uses captured time and Monday-start Europe/London calendar dates. Selection deduplicates species, caps manual selections at six and rotates six positions each UTC hour for overflow/all-time coverage.

`renderSvg` supplies deterministic 480×800 composition. `renderPng` embeds packaged bird PNGs and the bundled Caveat font, then rasterizes with resvg. It rejects remote art URLs and traversals. Palette, transparent illustrations and handwritten names retain upstream AvianVisitors vocabulary and licence attribution. `upstream-pack.js` reuses the upstream seeded silhouette-aware occupancy/spiral packing, with six-bird portrait area tuning and shrinking/recentering. Caveat labels use supporting baselines with reserved occupancy; the upstream curved contour-label engine is not reproduced. Missing artwork stays explicitly labelled. After approved artwork changes run `python app/renderer/build_masks.py` from the repository root; artwork without a generated silhouette is rejected explicitly.

From `app/`, run `RENDERER_TOKEN=<secret> npx tsx renderer/server.ts` (PowerShell: set `$env:RENDERER_TOKEN` first). Default port 8081; `PUBLIC_DIRECTORY` points to packaged `app/public`. GET `/health` is public; POST `/render` requires `Authorization: Bearer <RENDERER_TOKEN>` and JSON `{species,showNames,width:480,height:800}`. Worker must store successful PNG bytes in private R2 before publishing its revision. App preview and device image endpoints should return those same bytes.

Package the renderer with Node and native `@resvg/resvg-js` for the target Linux architecture. A shared inference container may supervise this server alongside Python and route `/render` to port 8081, or run a separate renderer container. Runtime integration remains the deployment owner's responsibility; local raster tests alone do not prove the deployed route.
